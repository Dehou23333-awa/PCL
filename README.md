# PCL RE（PCL Revived Edition）

PCL RE 是基于 [PCL2（Plain Craft Launcher 2）](https://github.com/Meloong-Git/PCL) 的第三方二次创作，一个 Minecraft 启动器。

本项目与 PCL 官方无关。
